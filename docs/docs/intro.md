# TradeSim

**TradeSim** is a full-stack, low-latency cryptocurrency trade simulator with predictive analysis, built from scratch.

- **Backend**: Python (FastAPI) — real-time trade logic and WebSocket-based orderbook feeds.
- **Frontend**: React + Vite — interactive UI and trading interface.

The simulator allows users to submit trades and view realistic results with latency, slippage, and predictive analytics using orderbook data.
